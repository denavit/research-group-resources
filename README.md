# Tensile Coupon Testing Guide

This guide is intended to help experimentalists perform tensile testing on steel coupons according to [ASTM E8](https://www.astm.org/e0008_e0008m-24.html) with the Instron machine in the Department of Civil and Environmental Engineering at the University of Tennessee, Knoxville. Not all details are described in this guide. 

The contents of this guide include:
* [Instructions for specimen preparation](specimen-preperation.md)
  * Drawings of samples 
* [Instructions for testing](testing-procedure.md)
  * [Example lab data recording sheet](data-sheet.xlsx)
* [Instructions for data analysis](data-analysis.md)
