# Required Materials
* Specimens (see notes [here](specimen-preparation.md))
* Data sheets (see example [here](data-sheet.xlsx))
* Gage punch
* Tape
* Pen, sharpie
* Micrometers
* Calipers
* Gloves

Note: The Instron machine, accessories, and grips are located in JDT 109. Prior to testing, reserve time for use of machine.

# Testing Procedure
1.  Log into the computer. The username is XXXX. The password can be found XXX.
2.  Log into the BlueHill software. The username is XXXX. The password can be found XXX.
3.  Install the appropriate accessories and grips. Note that different accessories and grips are used for different sample types.
    a. Machine setup for sheet size specimens
    b. Machine setup for plate size specimens
    c. Machine setup for round (threaded) specimens
4.  Connect the extensometer to the computer
5.  Select sample for testing
    a. Ensure the dimensions are measured and the gauge length is marked (see notes (here)[specimen-preperation.md]).
6.  Zero the load
7.  Install the sample in the Instron machine.
    a. Ensure that the sample is oriented vertically. 
    b. Ensure that the grips are in the wide portion of the sample.
8.  Attach the extensometer to the sample
    a. Ensure that the extensometer is oriented vertically and in its initial position.
9.  Press “run test” in the BlueHill software. 
10. Remove extensometer when prompted
11. Remove the specimen from the Instron machine after it has failed.
12. Press the return button on the computer to reset the position of the machine.
13. Measure and record final gauge length
14. Tape pieces of specimens together and label them with the specimen name.
15. If testing more specimens, return to step 5.
16. Once all specimens are tested, return all accessories and grips to their storage location. 
17. Retrieve data from the computer.

# Troubleshooting
* If the grips do not release the specimen after untightening, tap the wedges to overcome friction in grip.
