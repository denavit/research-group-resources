# Specimen Preparation #
1. Determine specimen type based on source material
2. Request machining from Andy Baker.
   - See sample drawings [here](sample-drawings)  
3. Mark gauge length with a punch.
4. Mark specimens so that they can be identified and distinguished even after testing. Consider using different numbers of punch marks in the grip length.
5. Take geometric measurements.
